Editing and saving

  • Connect folder (Chrome or Edge) — pick the folder this file sits in. Save then writes straight back into this HTML file, and dropped screenshots are written into images/ automatically. Grant permission once per session.
  • If the folder button does nothing, you are on file:// or a browser without the File System Access API. Serve the folder instead — python3 -m http.server 8000 — and open http://localhost:8000. Or just use Save, which downloads a rebuilt copy of this file with every edit and image baked in; replace the old file with it.
  • Edit content turns every heading, step, caption and note into an editable field. Add and remove steps, operators, notes and whole tools with the small buttons that appear. Ctrl/Cmd+B bolds.
  • Screenshots — drag an image onto any slot. With a folder connected it lands in images/ under the filename shown; without one it is embedded in the file itself on save.
  • Nothing is stored in the browser. Unsaved work is lost on reload, so Save before you close.
